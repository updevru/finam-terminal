# Позиции

Вкладка «Позиции» — главный экран приложения. Здесь отображаются все открытые позиции на выбранном торговом счёте.

![](../../media/portfolio.png)

## Колонки таблицы

| Колонка | Описание |
|---------|----------|
| **Instrument** | Название инструмента (или тикер, если название недоступно) |
| **Qty (Lots)** | Количество в лотах. Положительное — длинная позиция (лонг), отрицательное — короткая (шорт) |
| **AvgPrice** | Средняя цена входа в позицию |
| **Current** | Текущая рыночная цена инструмента |
| **Daily P&L** | Дневной P&L — прибыль или убыток за текущий торговый день |
| **Value** | Стоимость позиции = текущая цена × количество |
| **Unreal P&L** | Нереализованный P&L — разница между текущей стоимостью и ценой входа |

## Обновление котировок

Котировки по выбранному счёту приходят потоком в реальном времени: колонка **Value** пересчитывается по мере сделок на бирже, а не раз в несколько секунд. Колонки **AvgPrice**, **Current**, **Daily P&L** и **Unreal P&L** приходят от брокера вместе с позициями и обновляются раз в 5 секунд.

- Подписка охватывает инструменты активного счёта и инструмент открытого [профиля](profile.md); при переключении счёта она автоматически переключается вместе с ним.
- Если поток обрывается (например, пропала сеть), приложение само возвращается к опросу цен раз в 5 секунд — данные продолжают обновляться, просто реже. Когда связь восстанавливается, поток подхватывается обратно.
- По остальным счетам цены всегда обновляются раз в 5 секунд.

Обновление данных вручную по-прежнему доступно по клавише **R**.

## Цветовая индикация

- **Зелёный** — положительное значение (прибыль)
- **Красный** — отрицательное значение (убыток)
- **Белый** — нулевое значение

Строки таблицы чередуются по цвету фона для удобства чтения.

## Действия

| Клавиша | Действие |
|---------|----------|
| ↑ / ↓ | Навигация по списку позиций |
| Enter | Открыть [профиль инструмента](profile.md) для выбранной позиции |
| A | Создать новую [заявку](trading.md#создание-заявки) по выбранному инструменту |
| C | [Закрыть позицию](trading.md#закрытие-позиции) — открывает окно с предзаполненными параметрами |
| ← / → | Переключиться на другую вкладку |
| S | Открыть [поиск инструментов](search.md) |
| R | Обновить данные |

## Пустой список

Если на счёте нет открытых позиций, таблица будет пустой. Используйте [поиск](search.md) (клавиша S), чтобы найти нужный инструмент и создать заявку.
