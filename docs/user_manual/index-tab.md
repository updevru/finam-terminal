# Вкладка «Индекс»

Вкладка **Индекс** — витрина ликвидных бумаг. Она отвечает на вопрос «а что вообще можно купить?», когда вы не знаете конкретного тикера: поиск (`S`) помогает только тем, кто уже знает, что ищет.

На вкладке показан состав **Индекса МосБиржи** (IMOEX) — около 46 крупнейших российских компаний, из которых индекс и рассчитывается. По каждой бумаге видны цена, изменение за торговую сессию и вес в индексе, а из любой строки можно в один шаг открыть профиль инструмента или окно покупки.

Данные вкладки **не зависят от выбранного счёта** — это витрина рынка, а не портфель.

## Как открыть

Вкладка — четвёртая в основной области: **Позиции | История | Заявки | Индекс**.

Когда фокус на основной таблице:

| Клавиша | Действие |
|---------|----------|
| → | Следующая вкладка (с «Заявок» — на «Индекс») |
| ← | Предыдущая вкладка (с «Позиций» — сразу на «Индекс») |

При первом открытии вкладка показывает `Loading index constituents...` — состав загружается из API. Дальше в течение сессии состав берётся из кеша, повторные заходы на вкладку ничего не запрашивают.

## Колонки

| Колонка | Что показывает |
|---------|----------------|
| **Ticker** | Тикер бумаги (SBER, GAZP, LKOH…) |
| **Name** | Название компании по-русски |
| **Price** | Последняя цена сделки |
| **Chg** | Изменение цены за торговую сессию в рублях |
| **Chg%** | То же изменение в процентах от цены закрытия предыдущего дня |
| **Weight** | Вес бумаги в индексе (сырое значение из API) |
| **Volume** | Объём торгов за день |

Строки отсортированы по весу — самые влиятельные бумаги индекса наверху.

Цвета: **зелёный** — рост за сессию, **красный** — падение, обычный цвет — изменения нет (`0.00`). Прочерк `—` означает, что котировка ещё не пришла или брокер не прислал это поле.

> **О колонке Weight.** Значения приходят из API как есть, и их шкала не описана в документации брокера (сумма весов заметно меньше 1, то есть это не доля в процентах). Поэтому вес показан сырым числом: для сортировки он надёжен, а трактовать его как «процент в индексе» было бы неверно.

## Клавиши

Когда фокус на таблице «Индекс»:

| Клавиша | Действие |
|---------|----------|
| ↑ / ↓ | Перемещение по списку |
| **Enter** | Открыть [профиль инструмента](profile.md) выбранной бумаги |
| **A** (или **Ф**) | Открыть [окно заявки](trading.md) на покупку выбранной бумаги |
| **R** (или **К**) | Обновить котировки вручную |
| ← / → | Переключение вкладок |

После выхода из профиля клавишей `Esc` вы возвращаетесь на вкладку «Индекс», причём выделенная строка сохраняется.

Окно заявки открывается обычным путём: с названием бумаги, текущей ценой и количеством в настоящих лотах — то же самое, что при покупке из поиска или из портфеля.

## Откуда берутся котировки

В обычном режиме цены приходят **потоком в реальном времени** — по тому же соединению, которое уже обслуживает котировки вашего портфеля. Бумаги индекса подключаются к потоку, только пока вкладка открыта, и отключаются, как только вы с неё уходите. Это сделано намеренно: вкладка, на которую никто не смотрит, не должна ничего стоить.

Первые цены появляются в течение примерно двух секунд после открытия вкладки — сервер сразу присылает снимок по каждой бумаге.

### Почему цены есть не у всех строк сразу

Брокер ограничивает число бумаг в одной подписке (точное значение не опубликовано; подписка на все 46 бумаг индекса отклоняется). Поэтому терминал подписывается не на весь индекс, а на **окно вокруг тех строк, что сейчас на экране**. При прокрутке окно едет вместе со списком, так что у строк рядом с курсором цены живые.

Если брокер отклонит даже такую подписку, терминал сам уменьшит её размер и повторит — без вашего участия. В журнале это видно как `[WARN] Broker refused a N-symbol quote subscription`. Котировки портфеля при этом всегда в приоритете: они стоят первыми в подписке и не вытесняются бумагами индекса.

### Если поток недоступен

При обрыве связи вкладка не остаётся пустой — она переходит на запасной режим:

- при входе на вкладку и сразу после загрузки состава котировки запрашиваются одним пакетом — по тому же окну видимых строк;
- клавиша `R` запрашивает их повторно в любой момент;
- автоматически пакет повторяется не чаще одного раза в минуту и только пока вкладка открыта.

Ограничения выбраны так, чтобы гарантированно оставаться внутри лимитов брокера. Если брокер всё же ответит отказом по превышению лимита, автоматическое обновление вкладки отключается до конца сеанса, в статус-баре появляется сообщение об этом, а ручное обновление по `R` продолжает работать.

### Защита котировок портфеля

Котировки портфеля важнее витрины. Если после подключения бумаг индекса общий поток котировок не поднимается в течение минуты (или срывается три раза подряд), бумаги индекса исключаются из подписки до конца сеанса: поток портфеля восстанавливается сам, а вкладка продолжает работать на запасном режиме. В журнале при этом появляется предупреждение.

## Возможные сообщения

| Сообщение на вкладке | Что означает |
|----------------------|--------------|
| `Loading index constituents...` | Состав индекса загружается |
| `<текст ошибки> — press R to retry` | Загрузить состав не удалось. Автоматических повторов нет — нажмите `R` |
| Прочерки `—` во всех числовых колонках | Состав загружен, котировки ещё не пришли |

## Ограничения

- В терминале доступен один индекс — Индекс МосБиржи. Из российских индексов API брокера отдаёт состав только для него.
- Значение самого индекса в пунктах не отображается — только состав.
- С вкладки доступна покупка; продажа выполняется из вкладки «Позиции».
